# Customer Order Count Analysis

## Project Overview
This project analyzes customer orders using the Sample Superstore dataset in Microsoft Excel. The main goal is to count unique orders placed by each customer and identify frequent buyers.

## Objectives
- Count unique orders for each customer.
- Identify customers who place orders frequently.
- Rank the top 10 customers by order count.
- Understand basic customer purchasing behavior.

## Tools Used
- Microsoft Excel
- Sample Superstore Dataset

## Project Steps
1. Imported the Superstore dataset into Excel.
2. Formatted the data as an Excel table.
3. Identified unique customers using Customer ID.
4. Retrieved customer names.
5. Counted unique Order IDs for each customer.
6. Sorted customers by order count to identify frequent buyers.

## Project Deliverables
- Customer order count table
- Top 10 customers table
- Original Superstore dataset

## Skills Learned
- Excel formulas
- Data cleaning
- Removing duplicates
- Customer-level data analysis
- Sorting and ranking
- Data interpretation

## Dataset
Sample Superstore sales dataset.

## Conclusion
This project demonstrates how Excel can be used to analyze customer ordering patterns and identify frequent buyers. The analysis provides a simple understanding of customer behavior.
